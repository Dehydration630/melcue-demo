# 首批试用指标设计（尚未收集）

| 要回答的问题 | 拟观察的信号 | 防止误读 |
|---|---|---|
| 用户是否感到被认真在意 | 自发继续解释作品、正负反馈与访谈原话 | 不把消息数量等同共鸣 |
| 第一次核心体验是否成功 | 听音完成、完整跟唱交付、用户实际播放 | 区分准备失败、播放失败与听感不喜欢 |
| 用户会不会再来 | 不靠主动提醒的后续访问与新内容 | 小样本只描述个案，不推算市场留存 |
| 工具是否产生启发 | 歌词保存、Mlog 修改/采用意图 | 生成数量不等于采用数量 |
| 等待是否可接受 | 首条回应、语音就绪、后台工作完成时间 | 报告分位数与失败样本，不只报最快 |
| 运行能否承受 | 每有效交流/每任务成本、重试与闲置成本 | 模型费用不等于全部云资源成本 |

先邀请少量真实音乐人，记录使用路径与反例；经过知情同意再汇总去标识化反馈。当前没有可对外宣称的实际增长或商业指标。
