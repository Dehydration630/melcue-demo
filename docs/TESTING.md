# 验证与复现

需要 Node.js 18+ 与 Python 3。无需安装包或配置密钥。

```sh
node --test tests/*.test.mjs
python3 scripts/check_publication.py
python3 -m http.server 8080 --bind 127.0.0.1
```

自动检查覆盖：完整句映射、无法匹配/未对齐时不伪造可唱结果、换会话/换作品/重复结果不交付、反差条件同时成立、认可后才保存，以及公开文件清单与本地链接。

手动交互步骤：

1. 点击“听听我新写的歌怎么样”，出现预置反馈后出现完整句的示意卡片。
2. 重置，准备中切换话题；旧跟唱结果不能出现在新话题。
3. 共创一句，拒绝不会保存；认可后歌词本计数为 1，重置后清空。
4. Mlog 邀约先拒绝，不出卡片；重新体验并接受，出现同一连续音乐片段的构思示意。
5. 在手机与桌面宽度检查可读性、键盘焦点和无水平溢出。

本仓库测试只证明演示代码行为，不证明真实模型、语音或剪辑质量。真实产品验收采用独立隔离数据，不随本仓库发布。
