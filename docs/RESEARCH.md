# 研究与假设

## 已有证据的来源

目前主要来自项目负责人作为音乐创作者的持续自测、提供原作与生活素材后的逐轮反馈，以及同类产品实测。样本有明显偏差，不能据此推出普遍需求或市场规模。

| 观察 | 带来的决策 | 仍需验证 |
|---|---|---|
| 抽象歌词直接具象化的视频不被采用 | 降低自动 MV 的中心地位 | 其他风格音乐人的接受度 |
| 真实排练素材的粗剪更有看点 | 以 Mlog 激发下一步素材探索 | 用户会不会修改、采用、发布 |
| 自己的歌被自然跟唱带来惊喜 | 跟唱作为首次交流的体验重点 | 新鲜感之后是否仍有价值 |
| 大段分析与物品罗列让聊天像报告 | 感受优先、按意图控制篇幅 | 主观理解是否稳定且不过度奉承 |
| 同一句认同后模型重复解释 | 管理当前交流动作与未完话题 | 长期聊天是否更自然 |

## 外部试用问题

邀请音乐人带一首真实作品与少量素材，先自由使用，再询问：哪一刻像有人认真听过？哪一刻让你出戏？你下一次会主动带什么来？不要只问“喜欢这个功能吗”。记录被采用的动作，同时保留拒绝与未完成案例。

## 竞品视角

创作、MV、剪辑和陪伴产品可能在功能上重叠。差异化假设是音乐人作品上下文中的持续关系与自然工具触发，不主张“没有竞品”或“其他产品均做不到”。本仓库不提供未经系统验证的市场排名。
